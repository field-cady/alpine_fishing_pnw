This directory holds scraped data.

## Files

- `state_lakes_<code>.jsonl` — one file per state, produced by `scrape_all.py`.
  Each line is a lake in the common schema (see `scrapers/base.py`).
  Codes: `wa` (Washington), `or` (Oregon), `id` (Idaho).
- `all_states.json` — every state's lakes concatenated by `merge_data.py`.
  This is the file the map frontend (`all_scripts.js`) loads.
- `idaho_high_mountain_ids.json` — cached IDFG high-mountain-lake id list,
  regenerated by the Idaho scraper.
- `oregon_kmls/` — cached ODFW map KMLs, regenerated by the Oregon scraper.

## Regenerating

```
python scrape_all.py      # writes data/state_lakes_*.jsonl
python merge_data.py      # writes data/all_states.json
```

Add `--smoke` to `scrape_all.py` for a quick, small check without a full scrape.
